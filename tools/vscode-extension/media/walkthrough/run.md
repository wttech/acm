# Run it

- **Run** above `doRun()`, the play button in the editor title, or `ACM: Run Script`.
- `ACM: Run Selection` runs just the selected lines; bare statements are wrapped in `canRun()`/`doRun()`.
- Scripts are compile-checked on save; errors show up in Problems.
- Every run is recorded in the ACM history: open it from the **Executions** view, read the log and download outputs.
- Cancel the progress notification, or click the status bar, to abort a running script.

On a `readonly` instance running is blocked; on any non-local instance you are asked first.
